# 🚋 Практична робота — Пошук "щасливих" трамвайних квитків

## ✅ Поставлене завдання №7
Трамвайні квитки мають шестизначні номери, вважають якщо квиток «щасливий» то сума перших трьох цифр дорівнює сумі останніх. Знайти кількість щасливих квитків

## 🔍 Суть завдання
"Щасливим" вважається трамвайний квиток, у якого сума перших трьох цифр дорівнює сумі останніх трьох.

Наприклад:

- 123321 → 1+2+3 == 3+2+1 → ✅
- 111222 → 1+1+1 ≠ 2+2+2 → ❌

Необхідно:

- Визначити загальну кількість таких квитків серед чисел 000000 до 999999.
- Додатково: визначити розподіл щасливих квитків за першою цифрою.

## 💻 Реалізація
📦 domain/Exercise.java

🔹 Метод Calculate()
- Перебирає всі номери квитків від 000000 до 999999.
- Для кожного квитка обчислює суму перших трьох та останніх трьох цифр.
- Якщо суми рівні — квиток вважається щасливим.
- Повертає загальну кількість щасливих квитків.

🔹 Метод calculateDigitSum(int number)
- Допоміжний метод для обчислення суми цифр числа.
- Працює з будь-яким тризначним числом.

🔹 Метод calculateWithFirstDigit(int firstDigit)
- Обчислює кількість щасливих квитків, які починаються з певної цифри (0–9).
- Формує діапазон від firstDigit * 100000 до firstDigit * 100000 + 99999.
- Порівнює суми перших і останніх трьох цифр.
